ABOUT PENNYWISE

PennyWise is a web application that helps shoppers in Pakistan find the cheapest available price for any product. We crawl real online stores, extract actual listed prices in PKR, and show them sorted lowest to highest with direct source links.

✓

PROTOTYPE GOALS

  • Let users search any product and see real prices from Pakistani online stores.
  • Sort results by price ascending so the cheapest option is obvious.
  • Strict data accuracy: Show only data actually collected from a real store page.
  • Keep the interface simple, consistent, and easy to build for a beginner team.
✕

NON-GOALS (PROTOTYPE)

  • Ticket search (events, cinema, bus, flights) — planned for subsequent phases.
  • Side-by-side product specification comparison.
  • Price history time-series, alerts, or wishlists.
  • User accounts, logins, and database admin panels.
Section 7 Compliance Strict Rule

THE ZERO-HALLUCINATION POLICY

The application must never display information that was not collected from a real store page. Prices are extracted via structured Schema JSON-LD, OpenGraph tags, or confirmed HTML price blocks and verified against store pages. Items with missing titles, missing prices, or missing URLs are permanently dropped, never repaired with placeholder data.

No Synthetic Data Live Real-Time Scrapes Direct URL Required

PROTOTYPE TECH STACK

Frontend HTML5 + TAILWIND

Retro arcade aesthetic with Pigeon's Mission tokens.

Interactive 3D SPLINE 3D VIEWER

Lazy-loaded interactive 3D coin mascot in hero.

Backend PYTHON & FASTAPI

Asynchronous API endpoints with OpenAPI docs.

Search Engine DUCKDUCKGO (DDGS)

Queries top Pakistani retail and e-commerce URLs.

Crawler & Extractor ASYNC HTTPX & BS4

Parallel page fetching with JSON-LD & regex waterfall.

Storage IN-MEMORY TTL CACHE

Thread-safe cache per query to prevent repeat crawls.
