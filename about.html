Price Comparison Engine Specification v0.1

About PennyWise

PennyWise helps shoppers in Pakistan find the cheapest available price for any product. We crawl real online stores, extract actual listed prices in PKR, and show them sorted lowest to highest with direct source links.

Prototype Goals

  • Let users search any product and see real prices from Pakistani online stores.
  • Sort results by price ascending so the cheapest option is obvious.
  • Strict data accuracy: Show only data actually collected from a real store page.
  • Keep the interface simple, consistent, and easy to build.

Non-Goals (Prototype)

  • Ticket search (events, cinema, bus, flights) — planned for later.
  • Side-by-side product specification comparison.
  • Price history, alerts, or wishlists.
  • User accounts, logins, and database admin panels.
Data Integrity Strict Rule

The Data Accuracy Policy

The application must never display information that was not collected from a real store page. Prices are extracted via structured Schema JSON-LD, OpenGraph tags, or confirmed HTML price blocks. Items with missing data are permanently dropped.

No Synthetic Data Live Scrapes Direct URL Required

Prototype Tech Stack

Frontend HTML5 + Tailwind

Dark luxury aesthetic with custom design tokens.

Animation DotLottie

Lightweight vector animations and loading spinners.

Backend Python & FastAPI

Asynchronous API endpoints with OpenAPI docs.

Search Engine DuckDuckGo

Queries top Pakistani retail and e-commerce URLs.

Crawler Async HTTPX & BS4

Parallel page fetching with JSON-LD & regex.

Storage In-Memory TTL Cache

Thread-safe cache per query to prevent repeat crawls.
